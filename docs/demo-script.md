# 3–5 minute demo

1. Sign in as the patient and run **Emergency red flag**. Show the deterministic override, Emergency guidance, timeline, citations, and reviewer escalation.
2. Start a new intake and run **Self-Care agreement**. Show the exact two-key approval and complete teach-back.
3. Run **Critic disagreement** to show that disagreement fails closed to Same-Day review.
4. Sign in as the clinician. Open the encounter, inspect the Uncertainty Map and sentence provenance, edit one sentence, and sign the draft.
5. Sign in as the reviewer. Claim and resolve an escalation with a required note.
6. Sign in as the administrator. Show urgency mix, rule version, adapter posture, and the isolated read-only MCP snapshot.

Talking points: no diagnosis; deterministic rules first; two independent safety keys; uncertainty is visible; the full default workflow uses no paid AI credential.
